## Atualizações no aplicativo

- Verificação de versões estáveis ao iniciar e aviso quando há versão nova.
- Configurações → Atualizações: versão instalada, botão de verificar, último horário de consulta e opção de desativar a consulta ao iniciar.
- Download aberto no navegador para Setup ou Portable, conforme a versão em uso. A instalação permanece manual; o Jarumi não substitui arquivos durante o jogo.
- Mensagens de falta de rede, limite da API ou falha da consulta com possibilidade de tentar novamente.
- Interface em português, inglês e espanhol.

Baixe esta versão uma vez se estiver na 1.0.2 ou anterior. As próximas versões poderão ser verificadas pelo aplicativo.

## Downloads Windows x64

**Setup** instala o aplicativo. **Portable** executa sem instalação. Nenhum jogo está incluído; os dados permanecem no perfil Jarumi do usuário. Feche o aplicativo antes de instalar a nova versão ou substituir o Portable. Os executáveis continuam sem assinatura digital.

O pipeline valida comparação de versões, rede, pré-releases, destino dos downloads, preferência de startup, interface e IPC reais, além das regressões anteriores e testes do pacote.

Motor baseado em Rosabis/J2meJS e Mozilla PluotSorbet. As atribuições e a revisão ainda pendente das licenças dos componentes herdados permanecem documentadas no repositório.
