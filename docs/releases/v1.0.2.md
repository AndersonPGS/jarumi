## Downloads para Windows x64

- **Setup**: instalador do Jarumi.
- **Portable**: execute sem instalação; os dados continuam em %APPDATA%\Jarumi.
- **SHA256SUMS.txt**: hashes para verificar os arquivos baixados.

Não é necessário Node.js ou Java para executar. Nenhum jogo está incluído. Os executáveis não possuem assinatura digital. Não há atualização automática do aplicativo.

## Correções

- Slider de volume do PiP com largura utilizável, arraste de mouse e controle por teclado.
- Controles de tamanho, posição, transparência e volume reorganizados no estilo pixel art.
- Indicadores de volume sincronizados entre a tela de ajustes e o PiP.
- Releases com instalador e portátil geradas automaticamente ao enviar uma tag de versão, somente após os testes.

## Validação

O pipeline executa checks, testes HTTP/fontes, integração nativa, arraste de slider em 160/240/360 pixels e testes do aplicativo empacotado antes de publicar os executáveis.

Motor baseado em Rosabis/J2meJS e Mozilla PluotSorbet. As atribuições e a revisão ainda pendente das licenças dos componentes herdados permanecem documentadas no repositório; esta publicação não declara que essa pendência foi resolvida.
