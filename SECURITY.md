# Segurança

Não use issues públicas para enviar vulnerabilidades, dados de saves, jogos comerciais ou credenciais. Quando o repositório existir, use o canal privado de segurança do GitHub, se habilitado pelo mantenedor. Até lá, não há canal público de recebimento definido.

O projeto está em preparação, sem versão declarada como produção suportada. Não execute JARs de origem desconhecida. As validações automatizadas não são uma auditoria completa do motor ou do isolamento da máquina virtual.
